1. Introduction

This study investigates the performance of a longitudinal targeted maximum likelihood estimation (rTMLE) implemented in R on simulated cohorts. The primary objective is to evaluate the bias of this model, compared to the true* risk, in increasingly complicated reference scenarios. The hope is to recreate and validate models performance on LEADER-like data.

2.2. Performance measures

Two primary performance measures are considered in the simulation study: bias and root mean squared error (RMSE). These measures are used to evaluate the accuracy of the estimators relative to the true parameter or a specified reference value.

Let \(\hat{\theta}_n(t)\) denote the estimate obtained in simulation run \(n\) at time \(t\), and let \(\theta(t)\) denote the corresponding true parameter. The total number of simulation runs is denoted by \(N\). Bias describes the systematic deviation of an estimator from the true parameter. At a given time point \(t\), it is defined as

\[ \boxed{ \operatorname{Bias}(\hat{\theta}(t)) = E[\hat{\theta}(t)] - \theta(t) } \]

where \(E[\hat{\theta}(t)]\) denotes the expected value of the estimator. In practice the bias will be looked at run-by-run. To express the bias relative to the magnitude of the true parameter, the relative bias is defined as

\[ \boxed{ \widehat{\operatorname{Relative\ Bias}}(t) = \frac{ E[\hat{\theta}_n(t)] - \theta(t) }{|\theta(t) |}} \]

This provides a proportional measure of systematic estimation error, provided that \(\theta(t) \neq 0\). A positive relative bias indicates overestimation, while a negative relative bias indicates underestimation. RMSE measures the overall magnitude of estimation error across simulation runs, accounting for both systematic bias and variability between estimates.

For a specified reference value \(\theta^*(t)\), the RMSE is calculated as

\[ \boxed{ \operatorname{RMSE}(t;\theta^*) = \sqrt{ \frac{1}{N} \sum_{n=1}^{N} \left( \hat{\theta}_n(t) - \theta^*(t) \right)^2 } } \]

Here, \(\theta^*(t)\) represents the reference value at time \(t\), which may be the true parameter or an approximation obtained from a separate set of simulations. Similarly, the relative RMSE is defined as

\[ \boxed{ \operatorname{Relative\ RMSE}(t;\theta^*) = \sqrt{ \frac{1}{N} \sum_{n=1}^{N} \left( \frac{ \hat{\theta}_n(t) - \theta^*(t) }{|\theta^*(t)|}\right)^2}} \]

This expresses the RMSE as a proportion of the magnitude of the reference value, provided that \(\theta^*(t) \neq 0\).

2.2.1. Interpretation

Both bias and RMSE are included to provide complementary assessments of estimator performance. Bias quantifies systematic overestimation or underestimation, whereas RMSE captures the overall magnitude of estimation errors, incorporating both bias and variability.

The relative versions of these measures allow estimation errors to be interpreted proportionally to the magnitude of the true parameter or reference value, facilitating comparisons across scenarios with different parameter magnitudes.

All comparisons are performed at the same discrete time point \(t\), ensuring that estimates and their corresponding reference values represent the same follow-up period.

Throughout the simulation study, the term risk may be used as shorthand for the difference in cumulative risk between the two treatment protocols, unless otherwise specified.
